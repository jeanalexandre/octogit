## Objectif
Rendre cinq cas limites sûrs et lisibles : `FetchStatus` « hors ligne » quand le fetch automatique échoue faute de réseau ; liste des remotes quand une branche « Not published » est poussée dans un dépôt sans `origin` ; `SyncButton` et `PushButton` qui ne lancent jamais deux actions à la fois ; diff de plus de 5 000 lignes replié avec Show diff (le binaire est déjà tenu) ; refus de `xcode-select --install` affiché avec le message brut, la commande à copier et Copy.

## Critères d'acceptation
- **explorer-l-historique CA-5** : Étant donné le réseau coupé, quand un fetch automatique échoue, alors `FetchStatus` passe à l'état hors ligne, aucune branche locale ni l'arbre de travail ne change, et le graphe reste consultable.
- **synchroniser CA-14** : Étant donné une branche « Not published » dans un dépôt sans `origin` et avec au moins un remote, quand je clique sur `PushButton`, alors la liste des remotes s'affiche. Quand j'en choisis un, alors la branche y est créée sous le même nom et devient sa branche suivie. Quand j'annule, rien n'est poussé.
- **synchroniser CA-19** : Étant donné une action de `SyncButton` ou de `PushButton` en cours, alors le bouton affiche l'état en cours avec sa progression. Aucun des deux boutons ne peut lancer une autre action avant la fin de celle-ci.
- **preparer-un-commit CA-10** : Étant donné un fichier binaire, alors `DiffView` affiche « Binary file » avec les tailles avant et après, et Stage file reste disponible ; étant donné un diff de plus de 5 000 lignes, alors il est replié, s'affiche à la demande par Show diff, et Stage file reste disponible ; à 5 000 lignes ou moins, il s'affiche directement.
- **demarrer-un-depot CA-24** : Étant donné l'ouverture de l'installation d'Apple refusée par le système, quand je clique sur « Install Command Line Tools », alors `Welcome` affiche le message brut renvoyé par le système et la commande `xcode-select --install` avec Copy ; Copy place exactement `xcode-select --install` dans le presse-papiers. Dans cet état, « Check again » reste affiché et la revérification automatique continue : quand j'installe Git au terminal avec cette commande, le lancement reprend comme en CA-23, au plus tard 5 s après que `git --version` réussit, sans clic ni relance d'Octogit.
