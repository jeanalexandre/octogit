## Entrées de `RefContextMenu`
- **Branche ou `origin/…` source** : « Merge develop into feature/profiles » et « Rebase feature/profiles onto develop » ; la branche sélectionnée, sinon la courante, reçoit ; aucune entrée dans l'autre sens, aucune sur la branche qui reçoit, aucune quand une `origin/…` est sélectionnée. Merge toujours avec commit de merge, message par défaut de Git, sans édition.
- **Commit** : « Rebase feature/profiles onto c41d8e0 » (sans branche : rebase seulement, pas de merge) ; Cherry-pick, Revert ; « Reset feature/profiles to here › » Soft / Mixed / Hard, chaque mode décrit en une ligne ; « Interactive rebase from here » ; Create tag (nom, message optionnel ; nom pris ou invalide refusé) ; « Create branch here ».
- **Branche locale** : Checkout ; Rename (saisie en ligne ; lien de suivi gardé, `origin/…` non renommée) ; « Delete local » (désactivé sur la courante : « Current branch cannot be deleted. » ; sans confirmation seulement si fusionnée dans la courante ; fusionnée ailleurs : « feature/graph is not merged into feature/profiles (merged into origin/develop). Delete anyway? » ; fusionnée nulle part : « feature/graph has 3 commits not merged anywhere. Delete anyway? »).
- **`origin/…`** : Checkout (crée la branche locale qui la suit si besoin ; locale de même nom sur un autre commit : confirmation « feature/graph already exists locally. Reset it to origin/feature/graph? », commits de la locale absents de la distante listés (SHA abrégé, résumé), « Reset and checkout », « Checkout local as is », Cancel (Échap) ; même commit : checkout direct) ; « Delete from origin », toujours confirmé : « Delete feature/graph from origin? », puis « Local branch feature/graph is kept and will no longer track it. » si une locale la suit ; Cancel (Échap), « Delete from origin » ; aucune branche locale supprimée ; après suppression, la locale ne suit plus rien et affiche « Not published ».
- **Create tag** (sur un commit) : saisie en ligne du nom à la place de la `RefLabel`, message optionnel (tag annoté s'il est rempli) ; nom pris ou invalide refusé sous le champ (« Tag v1.1.0 already exists. », « Invalid tag name. »), Entrée sans effet tant qu'il est affiché ; Entrée crée, Échap annule ; le tag n'est pas poussé avec la branche.
- **Tag** : Push tag ; Delete tag (« Delete tag v1.2.0? », puis « It will also be deleted from origin. » ou « It exists only in this repository. » ; Cancel (Échap), Delete tag).
- **Stash** : Apply (stash gardé), Pop, Drop (confirmation nommant le stash).
- **Fichier non indexé ou non suivi** (`WorkingChanges`) : Discard changes (confirmation nommant le fichier ; non suivi : « ProfileBadge.svelte will be deleted. »).
- **Saisie en ligne du nom** (création, Rename) : à la place de la `RefLabel`, champ qui s'élargit au-dessus du graphe au-delà de la colonne des refs ; nom pris ou invalide refusé dès la saisie, message sous le champ (« Branch develop already exists. », « Invalid branch name. »), Entrée sans effet tant qu'il est affiché ; Entrée valide (création : crée et fait le checkout), Échap annule.
- **Désactivées, avec raison** : opération en cours (« Operation in progress. » : merge, rebase, Checkout, « Create branch here », Rename, « Delete local », « Delete from origin », reset) · HEAD détachée (Cherry-pick, Revert, Reset, Interactive rebase : « No current branch. ») · commit de merge (« Merge commits cannot be cherry-picked or reverted. », Reset reste disponible) · commit racine (« Root commit cannot be rebased. »). Opération en cours : rebase interactif, cherry-pick et revert désactivés sans raison affichée. Aucun raccourci ne lance une entrée désactivée.
- **Messages** : « Already up to date. » (merge ou rebase sans effet) ; modifications non commitées : « Commit or stash your changes before merging. » (« … before rebasing. », « … before cherry-picking. », « … before reverting. ») ; checkout : « Commit or stash your changes before switching branches. » ; cherry-pick sans changement : « c41d8e0 brings no changes to feature/profiles. » ; refus de Git : message d'une ligne et « Details ». Rien n'a bougé après un refus.

## Blocage d'identité (J-13)
- **Conformité** : quatre valeurs comparées au profil (`user.name`, `user.email`, `core.sshCommand`, signature).
- **`WorkingChanges` bloqué** : « Identity does not match profile Work. », puis, par valeur en écart, « Expected: <valeur du profil> » et « Found in .git/config: <valeur locale> », et « Fix repository identity ».
- **Actions refusées** (non conforme ou « No profile ») : Commit, Amend, merge, cherry-pick, revert, rebase, rebase interactif, Continue de `ConflictResolver`, Push, Force push et « Delete from origin », avec la même raison. Checkout, Branch, « Create branch here », Rename et « Delete local » restent disponibles. Reset Soft / Mixed / Hard reste disponible.
- **`PushButton` bloqué par les commits à pousser** : committer toujours comparé au profil ; auteur bloquant seulement s'il est un autre de mes profils (un collègue ne bloque pas) ; seuls les commits absents de toute branche distante du remote cible comptent. Message « 1 of 2 commits authored as jag@perso.fr. Profile Work expects jag@work.fr. » ou « 1 of 2 commits committed as <nom et adresse>. Profile Work expects <nom et adresse de Work>. », puis chaque commit (SHA abrégé, résumé) marqué « ✕ author », « ✕ committer » ou « ✓ ».
- **« Fix commit identity »** : un geste, réécrit tous les commits fautifs, quelle que soit leur position ; Work comme committer, Work comme auteur seulement si l'auteur était un autre de mes profils, sinon auteur d'origine gardé ; ensuite push normal, jamais Force push. Refusé avec des modifications non commitées : « Commit or stash your changes before fixing commit identity. ».
